# Revisi UX Final

Keputusan final sebelum pengembangan Android penenun:

1. Landing page hanya untuk pengunjung dan fokus pada informasi/ajakan melihat koleksi.
2. Pembeli login tidak memiliki Beranda terpisah; Koleksi menjadi halaman utama.
3. Search berada di bawah header, bukan di tengah navbar.
4. Akun Saya hanya untuk profil pengguna.
5. Pesanan dan Keranjang memakai halaman sederhana tanpa sidebar/card ringkasan tambahan.
6. Login/Daftar memakai ikon mata untuk password dan tombol kembali tanpa panah.
7. Dashboard Admin menampilkan statistik operasional penting.
8. Produk, Stok, dan Target Produksi dipisahkan secara konsep dan navigasi.
9. Menu fitur lanjutan boleh sudah terlihat, tetapi halaman tetap kosong sampai fungsi benar-benar diimplementasikan.
10. Struktur tetap satu project Laravel; Flutter penenun akan memakai REST API Laravel dan database pusat yang sama.
