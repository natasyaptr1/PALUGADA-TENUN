# Perbaikan Footer dan Dashboard

1. Footer publik dibuat tiga bagian: identitas singkat, tautan jelajah, dan lokasi.
2. Masuk/Daftar dipindahkan ke baris paling bawah agar footer tidak terlihat seperti navbar kedua.
3. Bagian Perlu Perhatian pada dashboard admin dihapus karena informasi target/stok sudah tercermin pada statistik utama.
4. Panel Pesanan Terbaru dibuat memenuhi lebar dashboard.
