# Revisi UX V3 Palugada Bandar

## Pembeli
- Setelah login, halaman utama adalah `/akun`.
- `/akun` berisi identitas singkat, showcase produk terbaru, dan pesanan terbaru.
- Menu pembeli: Koleksi, Pesanan, Keranjang, Akun Saya, Keluar.
- Tidak ada menu Beranda untuk pembeli yang sudah login.
- Halaman Pesanan, Keranjang, dan Profil tidak memakai sidebar tambahan.

## Pengunjung
- `/` adalah landing page promosi Palugada Bandar.
- `/katalog` adalah satu halaman Koleksi yang berisi pencarian, filter jenis, kartu produk, dan detail produk.

## Admin
- Sidebar hanya berisi menu utama tanpa kartu promosi di pojok bawah.
- Produk & Stok serta Data Penenun tetap aktif.
- Target Produksi, Pesanan, Pembayaran, dan Laporan tetap terlihat agar struktur tidak berubah pada sprint berikutnya, tetapi halaman saat ini hanya menampilkan keadaan kosong.

## Login dan Registrasi
- Kalimat teknis mengenai akun Admin/Penenun dihapus dari tampilan.
- Kata sandi dapat dilihat atau disembunyikan.
- Tersedia akses kembali ke Palugada dan Koleksi.

## Tampilan
- Background utama cream pucat.
- Hijau Palugada tetap menjadi warna identitas utama.
- DM Sans digunakan untuk teks antarmuka dan DM Serif Display untuk judul editorial.
- Ukuran font, simbol, tombol, dan form diperbesar agar lebih nyaman digunakan.
